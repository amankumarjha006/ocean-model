# Ocean Data Directory

This directory stores oceanographic data, metadata definitions, and sample datasets for the 3D Ocean Data Visualization System.

## Contents

- `sample_metadata.json`: Static canonical JSON export of the 4D Ocean Model dataset metadata (CF-1.8 compliant) matching the `/api/dataset` schema.
- In later phases: NetCDF (`.nc`), GRIB2, and in-situ Argo/Glider profile CSV/JSON files will be placed here or streamed via remote OpenDAP/THREDDS endpoints.
